# Developer Productivity Analytics

This project explores how the conditions of a coding session may relate to developer productivity. It is a practical exercise in using Python and statistics to inspect, clean, summarize, visualize, and reason about data.

## Project Overview

The analysis uses session-level information such as:

- session date, day, start time, and duration
- interruptions and meeting overlap
- caffeine, focus, and energy
- completed tasks, introduced bugs, and a productivity score

The notebook works through a complete analysis workflow:

1. Inspect the dataset structure, data types, missing values, invalid ranges, duplicates, and extreme observations.
2. Clean and prepare variables for analysis.
3. Use descriptive statistics, visualizations, and correlations to explore patterns.
4. Apply probability and Bayes reasoning to questions involving focus and productivity.
5. Test whether high-focus sessions have higher average productivity than low-focus sessions.

## My Conclusions

The analysis suggests that sessions with higher focus levels tend to have higher productivity scores. Also, other parameters such as caffeine intake appears to be positively associated with focus and productivity.

However, the dataset is synthetic and illustrative, so these findings are not generalizable to real-world developer behavior.

## Important Dataset Note

**developer_productivity.csv** is an AI-generated, contrived dataset created for learning and practice. It is not collected from real developers. The values and relationships are illustrative and should not be treated as real-world measurements, reliable benchmarks, or evidence for workplace decisions.

Consequently, the findings in the notebook demonstrate statistical techniques rather than claims about actual developer behavior. The conclusions apply only to this practice dataset.
